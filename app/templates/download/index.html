Instalacija Blagajne

Slijedi korake redom: certifikat, App Installer (ako ga nema), zatim Blagajna, Printer Hub, RunDesk Client i Tailscale.

Korak 1

Obavezno

Korak 1: Instaliraj certifikat

Preuzmi i instaliraj certifikat da bi Windows vjerovao aplikaciji.

Preuzmi certifikat
  • Dvoklik na preuzeti .cer
  • Install Certificate -> Local Machine ili Current User ako nema admin prava
  • Odaberi "Trusted Root Certification Authorities"
  • Ponovi i instaliraj u "Trusted Publishers"

Napomena: bez ovoga MSIX instalacija nece proci.

Korak 2

Preduvjet

Korak 2: Instaliraj Microsoft App Installer (bez Store-a)

Za Windows 10 bez Microsoft Store-a prvo instaliraj Microsoft App Installer iz .msixbundle paketa.

Preuzmi App Installer (v1.28.190)
  • Preuzmi Microsoft.DesktopAppInstaller_8wekyb3d8bbwe.msixbundle
  • Pokreni paket i potvrdi instalaciju
  • Nakon toga nastavi na Blagajna i Printer Hub .appinstaller linkove

Napomena: ovaj korak treba napraviti samo ako App Installer nije vec instaliran.

Korak 3

Aplikacija

Korak 3: Instaliraj aplikaciju (Blagajna)

Instalacija se pokrece nakon klika na gumb. Trenutni release za Blagajna auto-update je 1.0.6.0.

Instaliraj Blagajna Preuzmi MSIX 1.0.6.0
  • Ako nemas App Installer, preuzmi ga iz Microsoft Store-a ili kroz korak 2

Korak 4

Printer

Korak 4: Instaliraj Printer Hub

Printer Hub je potreban za lokalni print racuna i komunikaciju s printerom.

Instaliraj Printer Hub (Auto-update) Preuzmi MSIX 1.0.12.0
  • Pokreni MozzartPrintHub.appinstaller
  • Potvrdi otvaranje kroz App Installer
  • App Installer ce automatski pratiti i instalirati nove verzije

Napomena: trenutna verzija je 1.0.12.0 i update ide automatski kroz App Installer.

Korak 5

Podrska

Korak 5: Instaliraj RunDesk Client

RunDesk Client koristi se za udaljenu podrsku i pristup.

Instaliraj RunDesk Client Preuzmi MSIX 1.4.7.0
  • Pokreni RunDesk.Client.appinstaller
  • Potvrdi otvaranje kroz App Installer
  • Ako treba, koristi direktni MSIX link kao fallback

Napomena: preporuceno je pokretanje preko .appinstaller zbog update mehanizma.

Korak 6

Mreza

Korak 6: Instaliraj Tailscale

Preuzmi i instaliraj Tailscale klijent, pa ga spoji na privatni login server.

Preuzmi Tailscale
  • Pokreni tailscale-setup-latest.exe i dovrsi instalaciju
  • Otvori Command Prompt ili shell
  • Pokreni tailscale up naredbu za spajanje na login server

Napomena: nakon instalacije pokreni naredbu iz sekcije ispod.

Mini FAQ

Sto ako MSIX javlja gresku o certifikatu?

Certifikat nije trustan. Instaliraj ga u Trusted Root i Trusted Publishers.

Sto ako nema App Installer?

Preuzmi App Installer iz Microsoft Store: https://aka.ms/getwinget

Treba li mi Printer Hub?

Da, za lokalni ispis racuna Printer Hub mora biti instaliran i pokrenut.

TouchScreenPOS 1.0.6

Za rucni deployment ili lokalnu instalaciju dostupni su i aktualni 1.0.6 release artefakti.

MSI 1.0.6 ZIP x64 1.0.6

RunDesk fallback (0x80072F76)

Ako App Installer padne s greskom 0x80072F76, koristi fallback: direktni download MSIX + Add-AppxPackage.

$u='https://mozart.sibenik1983.hr/download/RunDesk.Client_1.4.7.0_x64.msix'
$f="$env:TEMP\\RunDesk.Client_1.4.7.0_x64.msix"
Invoke-WebRequest $u -OutFile $f -UseBasicParsing
Add-AppxPackage -Path $f -ForceUpdateFromAnyVersion
Preuzmi RunDesk fallback .ps1

Tailscale povezivanje

Nakon instalacije Tailscale-a kopiraj i pokreni ovu naredbu u Command Promptu ili shellu:

tailscale up --login-server https://hs-control.qubitsecured.online/
